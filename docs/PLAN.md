# 서비스 기획서: 오늘의 코디 챌린지

## 1. 서비스 목적
옷 고르는 게 막막한 사람에게 "상황 → 코디 → 피드백"을 게임처럼 반복하며 코디 감각을 익히게 한다.
AI가 즉시 점수와 이유를 말해 주고, 다른 사람의 별점으로 취향을 비교해 볼 수 있다.

## 2. 타겟 사용자
- 매일 아침 "뭐 입지"를 고민하는 20대 대학생·사회초년생
- 패션에 관심은 있지만 조합에 자신이 없는 사람
- 친구와 코디를 비교하며 가볍게 놀고 싶은 사람

## 3. 페이지 구성 (상단 메뉴로 이동)
| 페이지 | 파일 | 내용 |
| --- | --- | --- |
| 홈 | index.html | 서비스 소개, 랜덤 코디 마네킹, 시작 버튼 |
| 코디하기 | game.html | 상황 카드, 캐릭터 성별 선택, 옷장(5개 카테고리), 아바타 미리보기, AI 평가, 런웨이 출전 |
| 런웨이 | runway.html | 출전한 코디 갤러리, 별점 주기(코디당 1회) |
| 랭킹 | ranking.html | AI 점수 + 별점 합산 순위 상위 20개 |

## 4. 핵심 기능
1. **상황 카드**: 8가지 상황 중 랜덤 제시, 다시 뽑기 가능
2. **캐릭터 선택**: 여성/남성 중 선택. 헤어스타일로 구분되며 런웨이 카드에도 반영
3. **옷장 코디**: 상의·하의·신발(필수) + 아우터·소품(선택). 옷 종류마다 다른 실루엣을 SVG로 그려 아바타에 즉시 반영
4. **AI 스타일리스트 평가**: 100점 만점 점수, 적합도 한 줄, 코멘트 2문장
5. **런웨이 전시 + 별점**: 코디를 공개 저장소에 올리고 방문자가 1~5점 부여
6. **랭킹**: 종합 = AI 점수 × 0.5 + 별점 평균 × 10

## 5. AI 기능 정의
- **입력**: 상황 문장(제목 + 설명), 선택한 아이템 목록(카테고리: 이름)
- **처리**: `api/evaluate.py`가 채점 기준(적합도 40 / 색 조합 30 / 완성도 30)을 담은 시스템 프롬프트와 함께 Google Gemini API(`gemini-3.5-flash-lite`)를 REST로 호출. `responseMimeType: application/json`으로 JSON만 받도록 지시
- **출력**: `{ score: 0~100, fit: "…", comment: "…" }`
- **사용자 가치**: 왜 좋고 나쁜지 바로 알 수 있어 다음 코디에 반영 가능
- **캐릭터 '마담 룩'**: 짧고 유쾌한 말투, 칭찬과 지적을 한 문장씩

### 실패 처리 기준
| 구분 | 조건 | 처리 |
| --- | --- | --- |
| 빈 입력 | 필수 카테고리 미선택 또는 코디 이름 없음 | 요청 전 차단, 누락 항목 안내 |
| API 오류 | 4xx/5xx 응답 | 상태 코드 + Gemini 메시지 표시, 버튼 다시 활성화 |
| 타임아웃 | 브라우저 30초 / 서버 20초 내 무응답 | 안내 후 재시도 가능 |
| 파싱 실패 | AI가 JSON이 아닌 답을 줌 | 정규식으로 `{…}` 추출 시도 후 실패 시 안내 |
| 사용량 초과 | Gemini 무료 티어 한도(429) | 잠시 후 재시도 안내 |
| 과금 방지 | 세션당 5회 초과, 응답 토큰 400 제한 | 안내 메시지, 새로고침 시 초기화 |

## 6. 데이터 저장
- 런웨이 목록은 Upstash Redis의 키 하나(`runway:entries`)에 JSON으로 저장 (최대 100개 보관)
- 저장 항목: 코디 이름, 닉네임, 상황, 아이템(이름·색·실루엣 종류), 캐릭터 성별, AI 점수·코멘트, 별점 합계·개수
- 별점 중복 방지는 브라우저 localStorage에 "내가 준 코디 ID" 저장 (가벼운 수준)
- 이용자 수가 적다는 전제. 사용자가 늘면 항목별 키 분리와 서버 측 중복 방지로 확장

## 7. 기술 선택 이유
| 선택 | 이유 |
| --- | --- |
| Gemini API | Claude API는 별도 결제가 필요해 무료 티어가 있는 Gemini로 교체 |
| REST 직접 호출 | SDK가 실제 오류 메시지를 가려 디버깅이 어려웠음. REST로 바꾸자 "모델 제공 종료" 메시지를 바로 확인 |
| Upstash Redis | 별점을 "남에게" 받으려면 공유 저장소가 필요. localStorage는 브라우저별로 분리되어 불가 |
| SVG 직접 그리기 | 옷 이미지 저작권 문제 회피, 색·실루엣을 코드로 조합 가능 |

## 8. 차별 포인트
- 옷 이미지 없이 SVG 아바타로 원피스·후드·롱부츠·트렌치코트 등 실루엣까지 구분해 시각화
- 여성/남성 캐릭터 선택
- AI 점수(전문가 시선)와 별점(대중 시선)을 분리해 보여 줌
- 스타일리스트 캐릭터 '마담 룩'의 말투로 평가에 재미 부여
